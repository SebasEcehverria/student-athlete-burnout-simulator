Equations

Model

A readable guide to the variables, inputs, equations, Euler step, and burnout risk formula.

Variables

S(t) = stress

E(t) = energy

R(t) = recovery

Inputs

A = academic workload

T = training intensity

W = work responsibilities

L = sleep

P = social support

Scenario Mode

Scenario Mode uses one set of inputs repeatedly to simulate what could happen over a chosen number of days. This is useful for testing a schedule pattern like finals week or heavy training.

Personal Log Mode

Personal Log Mode uses saved daily log entries as changing inputs, so each Euler step is based on the recorded academic load, training, work, sleep, and support for that day.

Equations

dS/dt = aA + bT + cW - dR - eP

dE/dt = fR + gL - hS - iT - jW

dR/dt = kL + mP - nS - qT

Stress equation. Academic workload, training, and work responsibilities increase stress. Recovery and social support reduce stress because they give the athlete resources to handle the load. The coefficients control how strongly each factor pushes the stress rate up or down.

Energy equation. Recovery and sleep increase energy, which matches the idea that rest and rebuilding help an athlete feel more ready. Stress, training, and work drain energy because they demand time, attention, and physical effort.

Recovery equation. Sleep and social support help recovery build back up. Stress and training intensity reduce recovery because both make it harder for the body and mind to return to baseline.

Stress Equation Walkthrough

dS/dt = aA + bT + cW - dR - eP

Increases stress

+ aA = academic workload effect

+ bT = training intensity effect

+ cW = work responsibility effect

Decreases stress

- dR = recovery buffer

- eP = social support buffer

Energy Equation Walkthrough

dE/dt = fR + gL - hS - iT - jW

Increases energy

+ fR = recovery effect

+ gL = sleep effect

Decreases energy

- hS = stress drain

- iT = training drain

- jW = work drain

Recovery Equation Walkthrough

dR/dt = kL + mP - nS - qT

Increases recovery

+ kL = sleep recovery effect

+ mP = support recovery effect

Decreases recovery

- nS = stress recovery cost

- qT = training recovery cost

Euler's Method

The app approximates the solution one day at a time. For each day, it calculates the current rate of change, then updates the variable with:

next value = current value + dt * rate of change

Here, dt = 1 day, so each step represents one day in the simulated schedule.

Burnout Risk

burnoutRisk = stress - 0.5 * energy - 0.5 * recovery

Higher stress raises the risk score, while energy and recovery lower it. A high score means stress is dominating the protective factors in this simplified model.
