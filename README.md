# Student-Athlete Burnout Simulator

This project models student-athlete burnout using a coupled system of differential equations. The simulator tracks stress, energy, and recovery over time based on factors like academic workload, training intensity, sleep, work responsibilities, and social support.

The system is solved numerically using Euler’s Method, and the final project will include an interactive UI where users can adjust parameters and visualize how burnout risk changes over time.

## Main Variables

- Stress: how overwhelmed the student-athlete feels
- Energy: available physical and mental energy
- Recovery: how well the student-athlete is recovering from stress and workload

## Project Goals

- Build a meaningful Differential Equations model
- Solve the system numerically with Euler’s Method
- Create an interactive web simulator
- Visualize stress, energy, and recovery over time
- Connect the math model to a real student-athlete experience
